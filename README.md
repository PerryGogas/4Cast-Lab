**Train - Test - Forecast - Explain**

Latest version: 5.0 (October 2026)

**4Cast Lab** is a free research and teaching laboratory for **machine learning**, **econometrics** and **causal analysis**, designed for students, instructors and researchers.

- **Forecasting (ML):** train, tune and compare models honestly, out of sample; see what drives them; test causality (ML Granger causality, Double ML with refutation checks).
- **Estimation (Econometrics):** OLS, logit/probit, IV, ARIMA, ARDL, ECM, VAR/VECM and GARCH, with the standard tests.
- **AutoML:** a forecasting model in four steps, with an honest verdict in plain words.
- **Python Workbench:** Python inside the app, with a script of every run that checks each number.

**No coding or previous knowledge required.** Everything runs on your own computer.
