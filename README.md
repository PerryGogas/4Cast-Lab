# 4Cast Lab

**Train · Test · Forecast**: free machine learning and econometrics for Windows. No coding needed. Your data stay on your computer.

## Install

1. Download **4Cast.Lab.exe** from the [latest release](https://github.com/PerryGogas/4Cast-Lab/releases/latest).
2. Double-click it. There's nothing to install.
3. If Windows says "Windows protected your PC", click **More info**, then **Run anyway**. The app is free and not code-signed.

## Learn in 3 minutes

[Quick Start videos on YouTube](https://www.youtube.com/playlist?list=PLfIotCXrK6uc): Part A covers machine learning and Part B covers econometrics.
